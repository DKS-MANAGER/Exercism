# Exercism

Solutions to [Exercism.io](https://exercism.org) programming exercises — used for systematic improvement of Python (and potentially other languages) through mentor-reviewed practice problems.

## Stack
- **Platform**: exercism.org
- **Primary Language**: Python

## Structure
```
python/
  exercise-name/
    solution.py
    .exercism/
```

## Quick Start
```bash
# Install Exercism CLI
exercism configure --token=YOUR_TOKEN
exercism download --exercise=hello-world --track=python
```

Early stage — Feb 2026. Small repo (1KB), just initialized. Active learning track.
